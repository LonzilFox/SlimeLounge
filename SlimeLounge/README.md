# SlimeLounge v0.0.3

全像素 UI 的内部社交与小游戏站：聊天室、听歌室、好友、排行榜，以及五子棋 / 中国象棋 / 国际象棋 / 21点 / 德州扑克。

## 本地与线上

- `run_local.bat` 启动的是你电脑上的 Node 服务。默认监听 `0.0.0.0:8787`，同一局域网设备在防火墙允许时可通过启动窗口显示的 LAN URL 访问。你的电脑关机后本地版就停止。
- Cloudflare 部署版才是公网、无需你的电脑常开。
- v0.0.3 把“服务在线”和“房间 WebSocket”分开显示，并加入自动重连/keepalive，避免未进入房间也一直显示“已断开”。

## 唯一 Owner / Admin

推荐复制 `.dev.vars.example` 为 `.dev.vars`，在本地填写：

```text
OWNER_EMPLOYEE_ID=你的私密工号
```

Cloudflare 正式部署建议把 `OWNER_EMPLOYEE_ID` 配置为 secret。设置后，只有该工号首次注册时能成为唯一 Owner；其他人全部是 member。Owner 才能授予/撤销 Admin，Admin 不能继续创建 Admin。若不配置，为方便首次本地测试，空数据库的首个注册身份会成为 Owner。

## 工号冲突

- 工号对普通用户完全隐藏，只显示掩码给本人和管理端。
- 非 Owner 的新工号默认 `待核验`。
- 同一工号无法被第二个身份覆盖。
- 真实用户遇到“工号已占用”时，由 Owner/Admin 在管理页人工核验后驳回冒用身份或释放冲突工号。
- 换工号不会更换 `userId`、Lounge ID、好友或排行榜身份；普通成员换工号需要管理员审批。

> 仅靠工号格式和唯一性不能从技术上证明“输入者就是本人”。如果未来能接公司 SSO/邮箱验证，应升级为强验证。

## 聊天室

7 个讨论区：公告、大厅、技术/开发、游戏讨论、音乐讨论、闲聊、求助/建议。公告只允许 Owner/Admin 发言。布局使用 `100dvh`，滚动限制在频道/聊天等内部区域。

## 音乐搜索

输入歌曲或歌手名直接搜索，不要求粘贴链接。当前默认服务端尝试网易云网页搜索接口；公司网络若阻断 `music.163.com`，v0.0.3 会在约 2.5 秒内快速失败，不再长时间等待。可通过 `NETEASE_SEARCH_BASE` 指向你自己可访问的兼容搜索服务。

## 游戏房间

- 五子棋：5 间
- 中国象棋：3 间
- 国际象棋：3 间
- 21点：3 间，2~5 人
- 德州扑克：2 间，2~5 人

所有游戏均可加入 AI。只要桌上存在 AI 即为练习局：不进入真人排行榜；21点/德州真人筹码在练习局结束后恢复。

所有已入座真人必须点击“准备”，AI 自动准备；全部就绪才允许开始。

## AI

- 五子棋：胜负点检查、威胁评分、对手应手搜索。
- 中国象棋：合法着生成、子力/位置评估、Alpha-Beta 搜索。
- 国际象棋：合法着、王安全合法性、子力/中心/兵推进评估、Alpha-Beta 搜索。
- 21点：接近基础策略的软/硬牌决策。
- 德州：起手牌强度 + 公共牌 Monte Carlo + 底池赔率 + 加注/跟注/弃牌策略。

这是本地轻量搜索 AI，不宣称达到专业引擎/职业玩家强度。

## 棋盘

五子棋和中国象棋的棋子都落在**线的交叉点**，不是格子中心。国际象棋仍按标准方格落子。

## 对局切屏

站内导航在真人对局期间锁定。网页无法控制 Windows 的 Alt+Tab，也无法合法禁止用户切换其他应用，因此采用 `visibilitychange` 检测：真人排位局离开页面超过 2.5 秒后，棋类判负、21点自动停牌、德州自动弃牌。含 AI 的练习局不执行该处罚。

## 个人状态

支持：在线、忙碌、专注、开会、暂离、游戏中、听歌中，并可填写 48 字以内状态文字。好友列表与管理员用户列表都会显示。

## 运行

1. 双击 `setup.bat`。
2. 双击 `run_local.bat`。
3. 浏览器访问 `http://localhost:8787`。

无需 `npm install` 即可本地运行。Cloudflare 构建仍使用 Wrangler。
