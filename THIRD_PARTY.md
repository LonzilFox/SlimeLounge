# Third-party assets

## Riichi Mahjong tiles

SlimeLounge's riichi mahjong UI loads tile SVG artwork from **FluffyStuff/riichi-mahjong-tiles** (Regular set) through public CDNs. The upstream project states that all tile assets are in the public domain (CC0/public domain dedication).

- Project: https://github.com/FluffyStuff/riichi-mahjong-tiles
- License: https://github.com/FluffyStuff/riichi-mahjong-tiles/blob/master/LICENSE.md

The Mahjong Soul / 雀魂 proprietary artwork is not bundled or copied. SlimeLounge uses its own table layout and public-domain tile graphics.

## Fusion Pixel Font

UI 字体优先使用 Fusion Pixel Font（TakWolf），SIL Open Font License 1.1。项目通过 Web 字体服务加载，工程 ZIP 不内嵌字体二进制。

- https://github.com/TakWolf/fusion-pixel-font
- https://openfontlicense.org/
